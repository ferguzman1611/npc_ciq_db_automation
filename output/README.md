# output/

JSON files generated by the pipeline are written here after each run.

| File | Content |
|---|---|
| `global_attributes.json` | Single document with all global network attributes |
| `regional_attributes.json` | List of documents, one per region |
| `network_elements.json` | List of documents, one per network element |

Filenames are configurable via `.env`. Do not edit these files manually —
they are always overwritten on the next run.

> This folder is git-ignored. Never commit output files to the repository.
